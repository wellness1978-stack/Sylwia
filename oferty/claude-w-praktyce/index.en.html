Training program

Modules and topics

20 modules in three parts. Each module is a hands-on exercise and a result the participant keeps.

Part 1 · Everyday Claude
01

Setup and global instructions

  • Instruction layers: facts, assumptions, recommendations
  • Protecting verified values
  • Exercise: your own instruction tested in a new conversation
02

Projects and knowledge from documents

  • Project instructions and a source map
  • Unanswerable questions, conflicting and outdated documents
  • Exercise: a project that admits what it doesn't know
03

Prompts and critique

  • Context, audience, constraints and output format
  • Critique kept separate from revision
  • Exercise: a reusable prompt for the team
04

Research with verified sources

  • Perplexity, NotebookLM, Google AI Studio
  • Citation audit: supported and unsupported claims
  • Exercise: choosing the right tool for a specific task
05

Dashboard from CSV data

  • Field definitions, missing data, manual reconciliation of figures
  • Metrics, a chart and a filter
  • Exercise: a dashboard with a change log
06

Communication for audiences and channels

  • Executives, managers, sales; email, announcement, presentation
  • A/B variants without unsupported promises
  • Exercise: a message pack with a version comparison
07

AI audio and video

  • Voiceover narration and background music
  • Video with an avatar and a language version
  • Exercise: a comparison of variants and a production plan
Part 2 · Claude Code as a project office
08

Workspace and first assignment

  • A project folder instead of a chat: main instruction and skills
  • File versions instead of overwriting
09

Sources: what you read vs. what the AI reads

  • Live page vs. notes, honest source labeling
  • Verified facts saved in the project
10

Project memory

  • Memory as plain files: save, view, edit
  • Facts vs. decisions, change history
11

Skills: your team's procedures

  • Grill Me: better questions before the work starts
  • Verifying claims and modifying a skill
12

Proposal: choice, critique, visualization

  • Comparing variants and critique
  • A visual version in the browser or in Claude Design
13

Changing assumptions: your judgment vs. AI

  • First your own impact assessment, then a comparison with Claude
  • Updating memory with a decision history
14

A dashboard that helps you decide

  • Questions about the decision and the audience before any chart is built
  • Three personas, the same data, documented assumptions
Part 3 · Materials studio
15

From screenshot to website

  • Recreating a page from an image
  • Your own content, layout fixes, further versions
16

Company brand identity

  • A design system as a skill or Claude Design
  • Colors, typography, logo and consistency checks
17

Animated teaser

  • Script, pacing, animation and effects
  • Consistency with the event page
18

One change everywhere

  • One prompt updates the website, invitation and teaser
  • Before-and-after comparison
19

30-day trend radar

  • Sourced research and topic synthesis
  • Takeaways for communication
20

Showcase and rollout plan

  • Presenting results and a list of items to verify
  • First application in your own work
